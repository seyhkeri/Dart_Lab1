## Ответы на контрольные вопросы

### 1. Чем статическая типизация Dart отличается от Python? Какое практическое преимущество она даёт?
В Python применяется **динамическая** типизация - типы переменных проверяются во время выполнения (в рантайме), а сами переменные могут свободно менять свой тип. В Dart типизация **статическая (строгая)** - типы проверяются компилятором до запуска программы.  
* **Практическое преимущество:** Целый класс потенциальных багов ловится на этапе написания кода. Это ускоряет разработку, упрощает рефакторинг и исключает непредвиденные падения приложения у пользователя из-за несовместимости типов.

### 2. Что означает String?? Чем отличается от String?
* Одиночный знак вопроса (`String?`) делает тип **nullable** - это значит, что переменная помимо текста может хранить значение `null`.
* Запись `String??` не является самостоятельным типом - это ошибочная конструкция. Существует оператор `??` (Null-coalescing operator), который используется для подстановки значения по умолчанию, если левая переменная равна `null` (например: `String display = nickname ?? 'Аноним';`).
* Отличие от обычного `String` заключается в том, что стандартный `String` в Dart гарантированно **не может** быть равен `null`, что защищает программу от ошибок `NullPointerException`.

### 3. Зачем в Dart final, если в Python можно просто договориться не менять переменную?
«Договор» в Python держится только на дисциплине разработчика (например, использование UPPERCASE для констант) и легко нарушается случайной ошибкой. Ключевое слово `final` в Dart обеспечивает **жесткую проверку на уровне компилятора**. Если переменная помечена как `final`, компилятор физически заблокирует любую попытку её перезаписи, гарантируя стабильность логики приложения.

### 4. Чем именованный параметр {required String name} отличается от позиционного? Приведите пример вызова.
* **Позиционные параметры** передаются строго по порядку их объявления в функции, их имена при вызове не пишутся.
* **Именованные параметры** заключаются в фигурные скобки `{}`. Их можно передавать в любом порядке, но при вызове обязательно нужно указывать имя параметра через двоеточие. Ключевое слово `required` делает именованный параметр обязательным для передачи.

**Пример вызова именованного параметра:**
```dart
// Объявление функции
void printStats({required String name, required List<int> grades}) { ... }

// Вызов функции (порядок не важен, имена обязательны)
printStats(name: 'Артём Иванов', grades: [5, 4, 5, 3, 4, 5]);
```
